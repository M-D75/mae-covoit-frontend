# Icônes de suivi

- **Voiture vue de dessus** : SHMECTOR.COM, [fiche de l’auteur](https://shmector.com/free-vector/auto/car_top_view/11-0-138), [archive source](https://shmector.com/gallery/auto/car-top-view.zip), [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/). L’archive effectivement téléchargée contient CDR/EPS/AI, sans SVG malgré la description de la fiche. Conversion des onze tracés vectoriels EPS en SVG, rotation de −45° pour orienter l’avant au nord et recoloration grise par défaut, sans ajouter de détail à la silhouette. Aucun contenu distant exécuté, aucun raster incorporé. Fichier SVG conservé dans src/assets/maps/car-top-view.svg ; corps SVG embarqué dans actorMarkerPaths.js.
- **Piéton** : Google / Material Design Icons, [mdiWalk](https://pictogrammers.com/library/mdi/icon/walk/), @mdi/js 7.4.47 déjà installé ; [licence Apache 2.0 de la bibliothèque](https://pictogrammers.com/docs/general/license/), notice originale conservée dans mdi-LICENSE.txt. Tracé inchangé, mise à l’échelle et teinte dans une pastille de contraste.

Le miroir SVG Repo a été examiné (fiche CC0), mais ses fichiers ont refusé le téléchargement ; l’asset intégré provient directement de SHMECTOR. UXWing n’a pas été retenu pour éviter ses restrictions de redistribution indépendante.

La carrosserie seule est recolorable via actor.bodyColor (hexadécimal à six caractères validé) ; les vitres, feux et éléments du dessin d’origine gardent leurs teintes. La couleur déclarée du véhicule n’est pas injectée automatiquement. Le repère de voiture tourne seul autour de son centre (0° = nord, 90° = est). Le piéton reste vertical. Les deux moteurs utilisent le même corps SVG et la même ancre centrale. Les données d’image sont locales ; aucune requête d’icône pendant le suivi. Le fond de carte reste celui du fournisseur, sans promesse de style nocturne.
